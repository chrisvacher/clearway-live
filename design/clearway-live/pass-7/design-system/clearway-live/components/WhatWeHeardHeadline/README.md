# WhatWeHeardHeadline

A What We Heard headline built from accepted themes, with its source chips, counts and thin flag. Extends the pass 4 HeadlineDepth for setup, the TV and phones.

**Screens:** PRE-08. **Sets:** Setup, TV, phone. Design pass 6 (milestone 6).

**Consumer provides:** The number, the headline with a bold phrase, the detail, the sources with their counts, and the thin reason.

**Anatomy:** Setup: the number at 26px 700, the headline, source chips (survey, interviews, Four Helpful Lists) with counts, the thin flag, Show, edit and reorder. TV: the number in tv-display (Sunrise unless thin), the headline in tv-headline-xl light 300 with one bold phrase, the sources named. Phone: the headline, the detail, each source with its count.

| State | Behavior |
| --- | --- |
| Typed by hand | As in pass 4, marked Typed by hand |
| Built from themes | Sources and counts |
| Thin | Thin flag everywhere, number without Sunrise |
| On the TV | One at a time on the pre-call |

**Don't:** Put a paragraph on the TV, or hide where a headline came from.
