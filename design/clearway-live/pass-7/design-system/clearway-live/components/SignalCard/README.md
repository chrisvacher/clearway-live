# SignalCard

One alignment signal in the facilitator's private panel: its kind (aligned, divergent, silent, thin data), the theme and one line of evidence, with Open and Dismiss. Kinds are told apart by icon and label.

**Screens:** FAC-02. **Sets:** Control. Design pass 6 (milestone 6).

**Consumer provides:** The signal (kind, theme, line), whether it's saved as a citation, and the held silent count.

**Anatomy:** The existing cwl-signal card: the colored disc with its icon (circle-check, split, volume-x, circle-dashed), the kind in small caps, the theme, the line, Open and Dismiss. Saved shows bookmark-check. Cards come in over cwl-dur-signal-in, quietly.

| State | Behavior |
| --- | --- |
| Aligned, divergent, silent, thin data | Icon, label and line |
| Silent held | A dashed note until phones first go down |
| Saved | Saved as a citation for the report |
| Arriving | Soft fade and rise, no ring or sound |
| Dismissed | Leaves, list closes up |
| No accepted themes | The signal starts once themes are accepted |
| AI off | The signal is off |

**Don't:** Ever render on a TV, a participant's phone or a team facilitator's remote.
