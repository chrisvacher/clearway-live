# NotesUpload

Add leadership interview and input-conversation notes by paste, Word, PDF or text, see each file's state, and say which conversation it is.

**Screens:** SET-06. **Sets:** Setup. Design pass 6 (milestone 6).

**Consumer provides:** The files with their name, conversation kind (interview, elders conversation, staff conversation), state and word count or reason.

**Anatomy:** A dashed drop zone with Paste notes, the count of interviews and conversations, one row per file with its icon, name, kind select and state (uploading with progress, reading, read with words, couldn't read with the reason and an Error edge), and the privacy line: notes stay with Clearway.

| State | Behavior |
| --- | --- |
| Empty | Drop zone only |
| Uploading | Progress bar |
| Reading | Spinner |
| Read | Word count |
| Couldn't read | Error edge and what to do |
| Very long text | Name truncates, full name on hover |

**Don't:** Show notes to anyone but Clearway, or carry a name into a theme.
