# DuplicateFlag

Possible duplicate survey responses with what matched. Flagged for the facilitator, never blocked or removed, since a whole congregation can share church wifi.

**Screens:** SET-04. **Sets:** Setup. Design pass 6 (milestone 6).

**Consumer provides:** Pairs of responses with the same hashed network address, how far apart and how many answers match, and which are checked.

**Anatomy:** A card with copy, the count, and All kept in the results. Each pair names the responses, the network, the gap and the matching answers, with Mark as checked. A note explains church wifi.

| State | Behavior |
| --- | --- |
| Flagged | Pairs listed, all kept |
| Checked | The pair shows Checked |
| None | None flagged |

**Don't:** Offer to delete or exclude a response.
