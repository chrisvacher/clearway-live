# ReadBackPhone

The read-back on a phone: the lens's draft, the team's words underneath, the two answers and "What's missing?".

**Screens:** D2-04. **Sets:** Phone. Design pass 5 (milestone 5).

**Consumer provides:** the lens, correction states, the participant's answer and text, settled lenses.

**Anatomy:** Compact LensProgress, the heading, the paragraph with tracked changes, The team's words (anonymous, Show all), then Yes, that's us and It needs a change (`.p3-opt`); It needs a change opens What should change?. What's missing? and Send. Settled lenses can be read again (Looking back); never ahead.

| State | Behavior |
| --- | --- |
| Reading | Draft, team's words, two answers |
| It needs a change | A short box |
| Sent | Sent, or Saved on this phone offline |
| Looking back | A settled lens, Back to the current one |
| The close | Did we hear you right? and What's missing? |
| Phones down | Dimmed with their answer |
