# VoicesAndTensions

The voices not to lose and the tensions the room named, kept beside the paragraph so they aren't smoothed away.

**Screens:** OVN-02. **Sets:** Review. Design pass 5 (milestone 5).

**Consumer provides:** strong single lines from one person (anonymous) and the scribe's tension cards.

**Anatomy:** Two cards: Voices not to lose (mic) with the line and where it came from; Tensions the room named (zap) with both views. They go to the report, not into the paragraph.

| State | Behavior |
| --- | --- |
| Typical | One voice, one tension |
| Empty | Says none were kept |
