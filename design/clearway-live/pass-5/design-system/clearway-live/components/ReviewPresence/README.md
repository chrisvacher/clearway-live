# ReviewPresence

Who is reviewing which section, and the lock on a section the other facilitator is editing.

**Screens:** OVN-01. **Sets:** Review. Design pass 5 (milestone 5).

**Consumer provides:** both facilitators, where each is, whether each is editing.

**Anatomy:** Pills (`.cwl-ovn-who`) with initials avatar, You or the first name, and in or editing the section. The lock chip (`.cwl-ovn-lock`) carries the other facilitator's avatar, a lock and "Jaisy is editing".

| State | Behavior |
| --- | --- |
| Both | Two pills |
| Alone | One pill |
| Locked | Lock chip on the section |
