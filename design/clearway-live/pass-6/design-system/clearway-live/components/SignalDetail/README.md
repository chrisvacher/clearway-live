# SignalDetail

An opened signal: why it's showing (each source with its count, and what the room has said today), the neutral question, Put the question on the TV, Save as a citation for aligned signals, and Dismiss.

**Screens:** FAC-02. **Sets:** Control. Design pass 6 (milestone 6).

**Consumer provides:** The signal's evidence rows, the room's count and anonymous sentences, the suggested neutral question, and whether it's saved or the question is on the TV.

**Anatomy:** All signals back, the disc, kind and theme, Why it's showing with each source and its count, Said in the room today, up to three anonymous sentences, the neutral question in an editable box, Put the question on the TV (or Back to the wall), Save as a citation on aligned cards, Dismiss, and the note that the TV shows only the question.

| State | Behavior |
| --- | --- |
| Silent | Nothing said today |
| Divergent | The room's sentences beside what Discover says |
| Aligned, saved | Saved as a citation |
| Question on the TV | Back to the wall |
| Very long text | Wraps inside the panel |

**Don't:** Send data or the signal's name to the TV.
