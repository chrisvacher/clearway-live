# SignalList

The short list of current signals on the facilitator's own remote, so the signal works with the laptop closed. Each opens to its line of evidence. A team facilitator's remote never shows it.

**Screens:** FAC-03. **Sets:** Remote. Design pass 6 (milestone 6).

**Consumer provides:** The current signals, the open one, the held silent count, and whether the remote belongs to a team facilitator.

**Anatomy:** A private block in the remote with eye-off, Signal and the count, and Only you. Each signal is a row with its disc, kind and theme; the open row adds the line, Put the question up and Dismiss. Held silent signals are counted.

| State | Behavior |
| --- | --- |
| Closed | Rows only |
| Opened | Line and actions |
| Held | Silent waits for phones down |
| None | Starts once themes are accepted |
| Team facilitator | Not rendered at all |

**Don't:** Render on a team facilitator's remote.
