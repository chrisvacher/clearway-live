# FourListsCard

One Four Helpful Lists card: the text, its column and its agreement count, on the pass 2 card.

**Screens:** INT-11, SET-05. **Sets:** TV, phone, setup. Design pass 6 (milestone 6).

**Consumer provides:** The text, the agreement count and how many cards folded into it.

**Anatomy:** TV: cwl-card at its compact size, the text, then an AI badge with the folded count and the agreement pill (arrow-up and the count, outlined in cwl-text-on-card). Setup: the review card with agreement, a select box and the What We Heard and Strategic Tensions tags.

| State | Behavior |
| --- | --- |
| New | Lime ring for cwl-dur-new-hold |
| Folded | AI badge and the number of cards it holds |
| Zero agree | A lighter outline |
| Very long text | Wraps in full |

**Don't:** Show who wrote a card.
