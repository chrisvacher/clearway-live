# VersionHistory

Every version of a draft, with who changed it and when, and Restore.

**Screens:** OVN-02. **Sets:** Review. Design pass 5 (milestone 5).

**Consumer provides:** versions with number, author (a facilitator or the AI draft), time and what changed.

**Anatomy:** Rows (`.cwl-ovn-ver .v`): version number, avatar (the AI gradient for the draft), what changed and who and when, then Current or Restore.

| State | Behavior |
| --- | --- |
| Typical | Four versions, newest first |
| Restore | Makes a new version; nothing is lost |
