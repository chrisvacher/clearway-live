# The drag-to-build run of show and templates

Milestone 3, step 6b. SET-07 as design pass 3 change 15 has it (the run of show is built by dragging) and SET-08 (a template library with the team workshop template, Save as template, and Start an engagement from a template). Migration `templates`.

## Shared changes

Step 6b alone may change `show_read` and `show_write` (milestone 3 brief, wave 2). Only `show_write` is redefined:

- **`private.show_write`** keeps every action, check and status exactly, plus:
  - `save` takes an optional `index` for a new session: a drop lands at that place in its part, and the part's positions are rewritten 0 to n-1. A session moved to another part by its Part setting goes to the end of that part.
  - `place` (new): `{id, revision, part, index}` moves one session to a part and an index, for a dragged row or the keyboard. A stale revision is a conflict.
  - Every change recalculates the planned starts in each part it touched (`private.show_retime`).
- **A trigger on `public.sessions`** (`session_revision_keep`, after `session_revision`) keeps a session's revision when only its planned start was worked out from the durations, and only while `show_retime` runs. A worked-out time is not an edit, so an open editor and the stale-editor checks are unaffected.
- **Tokens:** `cwl-dur-app-hover` and `cwl-dur-panel`, from the design system's token file, were missing from `design/clearway-live/live_tokens.css` and are added.
- **Two TV layouts (step 1's):** the join strip now sits above the bottom-right count at every room size (it rises by the count's line height when that reaches into the scenes), and a holding outline of seven to twelve lines goes into two columns at the type floor, so it stays on screen. The content options say so (up to twelve lines).
- App: `session-form.tsx` gains an inline variant (Done, Save as draft, Remove, Discard changes, unsaved edits kept as a draft while the options are closed, and a worked-out start shown instead of the time field). It keeps step 6a's self-paced fields: choosing Self-paced fills a starting window, and Done and Save as draft save the open and close times. The per-kind options editors are unchanged. The browser kits for content, bars and grid-form-sign open sessions through the builder (Open options, Done) instead of the old side panel.

`show_read` is unchanged.

## SET-07: the run of show is built by dragging

- **Layout.** The left navigation and the run stay; the right column is a palette of every interaction the server runs (from the registry, in library order) and the six content screens (Scripture, Headline with depth, Prayer, Image, Holding, Screen check), each with a line on what it does. Parts (Pre-call, Day 1, Day 2, Follow-up) stay as groups in the run; an empty part is a quiet drop zone. A run with no sessions says Start the run, with Start from a template.
- **Dragging a tile** over the run opens a gap where it will land. Rows glide apart on springs (the TV's `springStep`) settling over `cwl-dur-make-room`, and keep their speed when the gap moves again. The place is read from the run as it would be without the gap, so the gap never chases the pointer. Dropping inserts the session there (saved at once, with every default) and slides its options open in place on `cwl-dur-panel`. Clicking a tile adds it at the end of the run (the last part with sessions, or Day 1).
- **Grabbing another tile slides any open options closed first**, so the run is short enough to drop into; the gap opens once they have closed. Unsaved edits are kept and the row says Unsaved edits until it is reopened.
- **Rows** show the time, the kind's icon, the title, the kind and length, and Ready or Draft (or Open, Live, Phones down, Closed for a running session). The grip drags a row to another place or part.
- **Options in place** are the session form (the same per-kind options editors). Done saves and marks the session Ready; Save as draft saves it as a Draft; Remove takes the session out (a Ready session asks first); Discard changes goes back to the saved session. A dropped interaction starts as a Draft with starting options that pass its check; a still screen (Prayer, Holding, Screen check) starts Ready; Scripture, Headline and Image wait as Drafts for their words or image.
- **Times recalculate from the durations.** A part starts at its first live session's planned start (or the earliest one set). Each live session starts when the one before it ends. Editing the first session's start moves the whole part; clearing it leaves the part untimed, and the run shows offsets (0:25). Self-paced sessions keep their own times and take no room time. The server does the same arithmetic on every change, so the builder, the print and the control surface agree. The header shows the session count and total length.
- **Keyboard.** Enter on a tile adds it at the end. Space on a tile, or Space or Enter on a row's grip, picks it up; the up and down arrows move the gap through every place in every part; Enter or Space drops it, Escape puts it back. A live region says what was picked up, where it is, and where it landed.
- **The screen stays alive.** A drop, a move or a removal shows at once; changes go to the server one at a time, in order, and the server's answer replaces the local copy without anything jumping. An open editor follows its session when the server only moved it or worked out a new start; a real edit elsewhere leaves Done reporting the conflict.
- **Self-paced sessions** (step 6a). The palette's Add as switch (Live in the room or Self-paced) adds an interaction as self-paced: a Draft with a window from the next whole hour for a week, set in the options with step 6a's Opens and Closes fields, then Done. Content screens stay in the room. A self-paced row shows Self-paced and its window ("Open until ..."), takes no room time, and retiming never moves its open or close times.
- **Reduced motion** puts rows in place at once and opens options without sliding.

## SET-08: templates

A template is a saved run of show (`private.templates`, forced row-level security, reached only through `template_read` and `template_write`). Each session keeps its part, place, title, interaction, prompt, phone depth, segment, lands in, settings, options, length, presenter notes and Ready or Draft. Times are kept as minutes from the template's first live start, so a template starts on any date. Each session keeps its mode; a self-paced session keeps its open and close times as minutes from that same start (negative when it opens before the first session), so Start an engagement shifts them exactly as it shifts live times. A template with no live times counts from its first self-paced opening. Answers, attendees, dates, room state and engagement ids are never kept. An image or document page keeps its image, copied to the new session on start.

- **The library** (`/setup/templates`, Templates in the run of show's navigation) lists the templates that ship with the app, those shared with the Clearway team, the facilitator's own, and for an admin every one. Each card shows the length, the session count and who saved it; the panel beside lists its sessions with their times.
- **Save as template**, from any run of show: a name and Share with the Clearway team (on by default). It says what it copies.
- **Start an engagement from a template**: choose the engagement (open ones the facilitator runs, every one for an admin) and when the first session starts, in the engagement's time zone. Every session is copied into the run of show, after any it already has, with its prompts, settings, timings and notes, all editable. A part that already had sessions keeps its start. It carries one room version. Engagements themselves are still created in setup from Team Hub; the dialog links there for an admin.
- **Remove template** for the owner or an admin. The shipped template can't be removed. Engagements started from a template keep their sessions.

**The team workshop template** ships in the migration (the Mentimeter replacement): 90 minutes, eleven sessions on Day 1, all Ready, each with presenter notes. Screen check, Welcome (holding, with a six-line outline), Opening prayer, Check-in (scale, Running on empty to Full and ready, with the join strip on), One word for this season (word cloud), What's working (open text), Where to focus (100 points, five focus areas, cut line after three), Effort and impact (2x2 grid with the same five), Your questions (Q&A), Our commitment (sign together) and Sending prayer. Scripture is left out on purpose: the facilitator pastes the passage in the engagement's translation (Decided November 2), so a template can't carry it. The Wayfinding and day-and-a-half templates are milestone 4.
